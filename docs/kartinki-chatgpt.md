# Картинки через ChatGPT в Chrome: что сломалось и как обходить (05.11.2026)

- Скрытые старые поля ввода остаются в DOM. Брать только видимое поле, иначе виден чужой текст.
- Новый запрос отправлять только после сохранения предыдущей картинки, иначе файл получит чужое имя.
- Новую картинку находить по адресам, которых не было до отправки; DOM хранит картинки из старых чатов.
- Картинка может появиться позже 35 секунд, даже когда кнопки «Стоп» нет. Ошибкой считать только текст ответа.
- Снимок загружается инструментом file_upload; из страницы скачать его нельзя, CSP блокирует fetch.
- ChatGPT иногда предлагает два варианта на выбор. Сохранять вариант 1 и кликать «Изображение 1 лучше», смотреть глазами.
- Другая вкладка может быть усыплена расширением, а само расширение Claude может отключиться: следить за паузой файлов.
- Каждую партию смотреть контактным листом. Проверка наличия: `python3 audit.py`.
